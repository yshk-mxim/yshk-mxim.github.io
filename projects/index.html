Open source

SKIFF: Container Manager for Zero Trust Environments
Open-source container manager built for GCP and zero-trust workstations. Avoids nested virtualization and privileged socket mounts. Talks to the daemon over SSH with nothing persistent on the container host. Four-tier test suite, 94% coverage floor, anti-pattern linter, and per-framework compliance evidence (OWASP ASVS, NIST SSDF, NIST CSF, SLSA, CIS Docker Benchmark). MIT-licensed.

Agent Memory: Persistent KV Cache for Multi-Agent Inference
MLX implementation of persisted 4-bit KV caches for multi-agent LLM inference on Apple Silicon, with background reloads and a demo app. Code for the Agent Memory Below the Prompt paper.
